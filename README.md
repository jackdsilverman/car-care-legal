# car-care-legal

Legal documents for the **Car Care** mobile app, served via GitHub Pages.

## Live URLs

After enabling Pages (Settings → Pages → Source: `main` branch, root):

- Landing: `https://jackdsilverman.github.io/car-care-legal/`
- Privacy Policy: `https://jackdsilverman.github.io/car-care-legal/privacy/`

## Editing

Files are Markdown with Jekyll frontmatter. Push to `main` and GitHub Pages will rebuild within a minute.
